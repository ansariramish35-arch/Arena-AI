# SwachhAI Project Submission

**SwachhAI — AI-Guided Waste Segregation and Circularity Assistant**

This folder contains the presentation prepared for the IBM University Engagement / AICTE-2026 project submission.

- [`SwachhAI_Project_Presentation.pptx`](SwachhAI_Project_Presentation.pptx) — editable 22-slide PowerPoint.

The deck maps SwachhAI to AICTE-2026 Problem Statement No. 6 (Eco Lifestyle Agent) and labels its architecture, worked examples and demo walkthrough as conceptual. It does not claim a deployed application, measured model performance, or field-test results.

The editable source and supporting certificate images are maintained in [`summer-internship-report`](../summer-internship-report/README.md); the deck can be rebuilt with [`build_presentation.py`](../summer-internship-report/build/build_presentation.py).
