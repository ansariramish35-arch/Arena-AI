THREE TYPES OF CASCADING STYLE SHEETS

1. INLINE STYLE SHEET

This paragraph is styled with the style attribute written directly inside the tag. Inline CSS has the highest priority.

Inline CSS is used to style only ONE single element.

2. INTERNAL (EMBEDDED) STYLE SHEET

This paragraph and the heading above are styled by the <style> block written inside the <head> section of this same page. Internal CSS applies to the whole page.

Type of CSSWhere it is writtenApplies to
Inlinestyle attribute of the tagOne element
Internal<style> block in <head>One page
Externalseparate .css file + <link>Many pages

3. EXTERNAL STYLE SHEET

This heading and paragraph are styled by the separate file external_style.css, which is attached to this page with the <link> tag. The same file can be attached to any number of pages of a website, so the design stays common everywhere.

This DIV also uses the external style sheet (class = "box").
